<h1 align="center">Netflix Movies & TV Shows Data Analysis Using SQL</h1>
 


 Project Overview :
 
This project focuses on analyzing Netflix Movies and TV Shows data using SQL in Google BigQuery. The goal is to explore content trends, identify patterns, and generate meaningful insights through data analysis.

Project Objectives :

- Analyze Movies vs TV Shows distribution.
- Identify the most popular genres and countries.
- Explore content release trends over the years.
- Analyze ratings, directors, and movie durations.
- Discover patterns in Netflix's content catalogue.

 Tools & Technologies:

- PostgreSQL
- SQL
- GitHub
- Kaggle Dataset

SQL Concepts Used:

- SELECT, WHERE, ORDER BY, DISTINCT
- GROUP BY and HAVING
- Aggregate Functions
- Subqueries
- Window Functions

 Dataset:

The project uses the Netflix Movies and TV Shows dataset available on Kaggle.

"Netflix Dataset – Kaggle" (https://www.kaggle.com/datasets/shivamb/netflix-shows)

Expected Outcomes:

- Understand Netflix content distribution.
- Identify trends across countries and genres.
- Develop practical SQL querying skills.
- Gain hands-on experience with PostgreSQL
- Extract meaningful insights from real-world data.
